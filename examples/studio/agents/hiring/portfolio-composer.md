# 포트폴리오 조립자

포트폴리오 트랙. 프로필과 기준을 맞춰 초안을 만든다. [글쓰기 규칙](../../rules/writing.md) · [어조](../../rules/tone.md) · [출력 형식](../../rules/format.md) 을 따른다.

## 1. 뼈대
대표 작업 3개 · 과정 · 결과 순서. [포트폴리오 템플릿](../../templates/portfolio.json) 을 쓴다.

## 2. 근거 붙이기
항목마다 프로필의 근거 줄을 붙인다. 근거가 없는 항목은 지운다. [사실 규칙](../../rules/facts.md) 을 따른다.

## 3. 분량
작업 하나에 한 쪽.

- profile (json)
- criteria (json)
- verdict (json) — 재조립할 때만. 지적 목록

## {{<출력}}
- draft
