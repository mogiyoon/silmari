# 이력서 조립자

이력서 트랙. 프로필과 기준을 맞춰 초안을 만든다. [글쓰기 규칙](../../rules/writing.md) · [어조](../../rules/tone.md) · [출력 형식](../../rules/format.md) 을 따른다.

## 1. 뼈대
경력 · 기술 · 학력 순서. [이력서 템플릿](../../templates/resume.json) 을 쓴다.

## 2. 근거 붙이기
항목마다 프로필의 근거 줄을 붙인다. 근거가 없는 항목은 지운다. [사실 규칙](../../rules/facts.md) 을 따른다.

## 3. 분량
A4 한 장.

## {{>입력}}
- profile (json)
- criteria (json)
- verdict (json) — 재조립할 때만. 지적 목록

## {{<출력}}
- draft
