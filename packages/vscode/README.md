# silmari

Checks the flow and data between md documents and shows them as a graph.

- Squiggles while you edit: missing files (L-N01), missing anchors (L-N09), data without a link (L-N13), references nobody calls (L-G01), and more
- `silmari: Show graph`: calls, send/receive, conditions and subagents between documents on one screen

Installing it turns on VS Code's Markdown link validation (`markdown.validate.enabled`). Your `settings.json` is not touched.
